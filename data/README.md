# 本地数据目录

与 `app/data_paths.py`、`ConfigManager.paths` 约定一致：

| 目录 | 用途 |
|------|------|
| `raw/` | 用户上传的原始文件；按案件分子目录 `raw/<案件ID>/` |
| `cache/` | 分析结果导出等缓存；默认导出对话框打开 `cache/<案件ID>/` |
| `sample/` | 单元测试或手工冒烟用的样本数据（可不入库） |

应用启动时会自动创建上述目录（若配置中路径被改写，则以配置为准并 `mkdir`）。

## 注意

- 勿将含敏感信息的 `raw/` 提交到公共仓库；必要时用 `.gitignore` 忽略。
- `sample/` 可放最小 CSV 供测试，文件名建议带业务关键字（如含「轨迹」「航班」）以便 Schema 匹配。
